Scene 呈现器注册表（方案 1）

一个 Scene + SceneMode。产品用可插拔呈现器替换 FakeScene 绘制；壳内不挂双 ViewHost。测试 session_wire 仍默认 FakeScene。

核心分层

app/mgis

  • 双 ViewportSurface（2D|3D）
  • SelectViewTab → SetSceneMode
  • 仅活动页 Attach；另一页 Detach
  • 只 include content/public

content/public

  • GisContents / SceneMode
  • AttachView(kViewIdScene)
  • scene_child_hwnd_for(mode)
  • 无 MapLibre / UE / FlyCube 头

content/browser

  • SceneImpl + 呈现器
  • SCENE2D → MapLibre（mercator 软回退）
  • SCENE3D → 试 UE 管 → FlyCube
  • product_presenters 注册工厂

原则：模式切换与 HWND

GisContents::AttachView("scene") ├─ 创建 2D 呈现器子 HWND └─ 试 PipeClient(\\.\pipe\mview) ├─ 成功 → UePresenter（presenter.3d ue） └─ 失败 → presenter.ue_failed → FlyCubePresenter（presenter.fallback flycube） SelectViewTab(2D|3D) → SetSceneMode → 活动页 NativeViewHost::Attach(child_for_mode) → 另一页 Detach（不 Destroy） → Resize + Present
