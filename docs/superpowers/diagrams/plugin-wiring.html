插件接线

方案 1：C ABI。壳持 Registry/Loader；PluginHost 在 GisContents；Interaction 真进 Workspace；右栏可列可跑。

分层

壳 app/mgis

  • Registry · Loader
  • 扫 UI/plugins → sample
  • ToolPluginPanel 点跑
  • 只 include content/public

plugin/

  • plugin.json + dll 字段
  • LoadLibrary / GetProcAddress
  • api/mview_plugin_api.h
  • sample → plugin_sample.dll

content/public

  • PluginHost
  • GisContents::plugin_host
  • set_tool_session

tool/

  • Workspace · Registry
  • 桥接后的 Interaction
  • ActivateInteraction

启动与贡献

Scan plugin.json→ LoadLibrary→ mview_plugin_contribute→ PluginHost 回调→ command / factory / menu / dock
factory→ 各视图 Workspace.registry→ ActivateInteraction

执行

右栏按钮 / Contribute→ PluginHost::run_processing→ mview_plugin_execute→ out/harness/…/mark.json

PluginHost 自身不 LoadLibrary。version 不符时 Loader 跳过并写 trace。
