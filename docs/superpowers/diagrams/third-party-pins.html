第三方依赖落点

清单在 third_party/manifest.json。GIS/工具库可按需引入；引擎与插件不进 aura/views 默认图。

已有快照

skia、zlib、libpng 等仍是 vendored，由 build.bat 的 GN 编译。zlib 不被 smartgis cmake 版覆盖。

smartgis 同步

sync_from_smartgis.py：清单 + 薄 GN + .src junction。排除 CEF / WebView2 / WinAppSDK / BCG。

按需工具库

rapidjson（pipe）、asio、gdal、PROJ、pdal 等：//third_party:<name>，默认不进产品图。

MapLibre / UE / Cesium / VTK

MapLibre ios-v6.30.0；UE 5.6 机外；Cesium 2.30；VTK 9.5.2 无 Qt。示例旁路壳。

Cesium for FlyCube

对照 Cesium for Unreal 的地理参考、AdditionalCameras、3D Tiles。网格上传到 FlyCube DX12。不进壳。

manifest.json → sync / fetch / junction → .src · .install → //third_party:<name>
content/browser/pipe → rapidjson （PipeJson 值模型）
壳默认 GN 不链接 GIS 大库 · VTK · MapLibre · UE · Cesium for FlyCube
cesium-native → Georeference / AdditionalCameras / Tileset → FlyCube upload buffer
