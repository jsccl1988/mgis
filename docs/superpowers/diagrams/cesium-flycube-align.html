FlyCube 运行时对齐 Cesium for Unreal

同一份 cesium-native。虚幻只留在标配进程里。

1 视图

Georeference、GlobeAnchor、AdditionalCameras、OriginShift。默认不漂移，远距离仍是 origin_conflict。

2 瓦片集

TilesetSettings 写入 TilesetOptions。加载失败和进度从 Tileset 读出。

3 影像

ion、TMS、WMS、WMTS、URL、Bing、Azure、Google、多边形、调试分色。像素按 UV 采样。

4 要素

_FEATURE_ID_0 与字符串属性列。属性纹理和数值列不在这一刀。

相机 / 锚点 ViewState Tileset::updateViewGroup TileMesh UV + RasterDrape FrameToPresent Present / FlyCube
刀 1：SampleRaster → 顶点色（CPU PNG 与 DX12 同源）
刀 2（未做）：真纹理 upload + HLSL 采样
不进入这条链：Pawn、材质、CesiumSunSky、编辑器、壳 GN
